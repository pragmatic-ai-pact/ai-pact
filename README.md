# The Pragmatic AI Engineer Pact

**A commitment to responsible and sustainable AI adoption.**

AI should help us become better engineers, not just generate more content. A 4,000-line PR may take minutes to produce, but it still takes time to review, validate, and maintain. When that work is pushed onto teammates, productivity gains become review burden and AI Brain Fry.

This Pact is not about restricting AI. It is about using it professionally and sharing its benefits.

## Participate

- **Discuss:** Share feedback, experiences, challenges, and lessons learned through [GitHub Discussions](https://github.com/pragmatic-ai-pact/ai-pact/discussions). You can also [open an issue](https://github.com/pragmatic-ai-pact/ai-pact/issues/new) to propose improvements or raise specific concerns.
- **Improve:** Help evolve the Pact by proposing focused changes through pull requests. See [`CONTRIBUTING.md`](CONTRIBUTING.md).
